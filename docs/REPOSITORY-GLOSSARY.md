# Repository Glossary

| Term | Definition in this showcase |
|---|---|
| Asset | Governed technology component used by an application or solution |
| Business capability | What the organisation must be able to do |
| Application portfolio | Managed set of applications linked to capabilities and technology |
| Standard | Approved or restricted technology position |
| Waiver | Time-bound, evidence-backed exception that does not change the standard |
| Inherent risk | Exposure before control effectiveness is applied |
| Residual risk | Remaining exposure after control effectiveness is considered |
| Architecture landscape | Connected current, transition and target-state relationships |
| Governance decision | Accountable outcome with rationale, conditions and evidence |
| Roadmap | Time-based transition from current to target state |
| Lifecycle forecast | Date-based support and retirement urgency assessment |
| Investment recommendation | Decision-support action such as migrate, modernise or retire |
| Reference architecture | Approved reusable target-state structure |
| Architecture pattern | Reusable response to a recurring architecture problem |
| Architecture building block | Reusable component in a reference or solution architecture |
| Traceability | Ability to navigate from strategy to evidence and back |
| Meta-field | Governed attribute describing an entity, relationship or decision |

# Technology Reference Model

## Version 1.1.0

The Technology Reference Model supplies the controlled taxonomy used to classify technology assets and standards.

```text
ENTERPRISE TECHNOLOGY
|
+-- EXPERIENCE
|   +-- Web
|   +-- Mobile
|   `-- Collaboration
|
+-- APPLICATION
|   +-- Business services
|   +-- Workflow
|   `-- Enterprise applications
|
+-- DATA
|   +-- Operational databases
|   +-- Analytical platforms
|   +-- Master data
|   `-- Metadata and governance
|
+-- INTEGRATION
|   +-- APIs
|   +-- Messaging
|   +-- Event streaming
|   `-- Batch integration
|
+-- AI
|   +-- Machine learning
|   +-- Generative AI
|   +-- Model operations
|   `-- AI governance

+-- SECURITY
|   +-- Identity
|   +-- Encryption
|   +-- Monitoring
|   `-- Data protection

+-- PLATFORM

|   +-- Operating systems

`-- OPERATIONS
    +-- ITSM
    +-- Observability
    +-- Configuration management
    `-- Automation
```

## Domain meta-fields

| Meta-field | Purpose |
|---|---|
| Domain ID | Stable taxonomy identifier |
| Domain name | Business-readable classification |
| Description | Scope of the domain |
| Architecture layer | Alignment to the architecture model |
| Owner | Accountable taxonomy owner |

# AI Governance Extension

Future AI features should:

- summarise evidence and findings;
- suggest missing metadata;
- compare current and target-state options;
- explain why a rule fired;
- retain source references;
- require accountable human approval;
- log prompts, model version, recommendation and final decision;
- prevent personal or confidential data from being sent to unapproved models.

```text
DETERMINISTIC CONTROLS -> EVIDENCE PACK -> AI EXPLANATION -> HUMAN DECISION -> AUDIT LOG
```

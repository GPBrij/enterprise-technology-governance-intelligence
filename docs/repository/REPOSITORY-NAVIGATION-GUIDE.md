# Repository Navigation Guide

## Start here

```text
Need an executive overview?       -> EXECUTIVE-REPOSITORY-VIEW.md
Need entity relationships?        -> REPOSITORY-RELATIONSHIP-MAP.md
Need metadata definitions?        -> metafields/
Need architecture viewpoints?     -> views/
Need end-to-end traceability?      -> traceability/
Need control ownership?           -> CONSOLIDATED-CONTROL-MODEL.md
Need lifecycle states?            -> CONSOLIDATED-LIFECYCLE-MODEL.md
Need target-state planning?       -> TARGET-STATE-AND-TRANSITION-MODEL.md
Need version history?             -> VERSION-AND-DOCUMENTATION-OVERVIEW.md
```

## Persona journeys

| Persona | Recommended path |
|---|---|
| Executive | Executive view -> coverage matrix -> investment and target-state views |
| Enterprise architect | Relationship map -> standards -> landscape -> decisions -> roadmap -> reference library |
| Solution architect | Application view -> technology view -> reference architecture -> patterns -> controls |
| Technology owner | Asset meta-fields -> lifecycle -> risks -> roadmap -> forecasts |
| Governance specialist | Controls -> waivers -> risks -> decisions -> evidence traceability |
| PMO / finance | Portfolio view -> roadmap -> forecast -> investment recommendation |
| Auditor | Licence -> governance decision log -> evidence view -> control model |

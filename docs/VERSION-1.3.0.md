# Version 1.3.0 Scope

## Architecture Repository and Application Portfolio

```text
BUSINESS CAPABILITY
        -> APPLICATION PORTFOLIO
            -> TECHNOLOGY ASSET
                -> TECHNOLOGY STANDARD
                    -> ARCHITECTURE WAIVER
                        -> TECHNOLOGY RISK
                            -> GOVERNANCE DECISION
                                -> TARGET STATE
```

## Controls

| ID | Control | Evidence |
|---|---|---|
| TG-REP-001 | Application linked to business capability | Capability ID |
| TG-REP-002 | Technology asset linked to application | Asset ID |
| TG-REP-003 | Landscape linked to applicable standard | Standard ID |
| TG-REP-004 | Governance decision recorded | Decision ID and evidence |
| TG-REP-005 | Target state defined | Application and landscape target state |
| TG-REP-006 | Repository traceability measured | Traceability score |

All data remains synthetic and portfolio-safe.

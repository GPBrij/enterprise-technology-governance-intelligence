# Version 1.5.0

Version 1.5.0 adds a Reference Architecture Library, Architecture Pattern
Catalogue, Architecture Building Blocks and a Pattern Alignment Engine.

```text
CAPABILITY -> REFERENCE ARCHITECTURE -> PATTERN -> BUILDING BLOCKS -> CONTROLS -> ALIGNMENT DECISION
```

Controls:

- TG-REF-001 Reference architecture approval
- TG-REF-002 Environment applicability
- TG-PAT-001 Pattern approval and review currency
- TG-ABB-001 Mandatory building-block completeness
- TG-CTL-001 Mandatory control evidence
- TG-ALN-001 Pattern alignment score and decision

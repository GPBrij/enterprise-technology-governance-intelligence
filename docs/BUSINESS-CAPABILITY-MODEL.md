# Business Capability Model

## Version 1.3.0

```text
STRATEGIC OBJECTIVE
        |
        v
BUSINESS CAPABILITY
        |
        +-- capability owner
        +-- current maturity
        +-- target maturity
        +-- target state
        |
        v
APPLICATION PORTFOLIO
```

## Meta-fields

| Meta-field | Purpose |
|---|---|
| Capability ID | Stable architecture identifier |
| Capability name | Business-readable capability |
| Description | Capability scope |
| Business owner | Accountable owner |
| Strategic objective | Strategy relationship |
| Current maturity | Current capability position |
| Target maturity | Intended maturity position |
| Target state | Future capability direction |

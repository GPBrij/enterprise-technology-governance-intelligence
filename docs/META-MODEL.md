# Technology Asset Meta-Model

```text
IDENTITY | LIFECYCLE | OWNERSHIP | HOSTING | SUPPORT | CAPABILITY | ARCHITECTURE | PRIVACY | DELIVERY | EVIDENCE
```

| Domain | Meta-fields |
|---|---|
| Identity | Asset ID, name, description, classification, version, vendor |
| Lifecycle | Status, support end date, current state, replacement target |
| Ownership | Technology owner, business owner, finance owner |
| Hosting | Environment, on-premises/cloud/hybrid |
| Support | Internal support, external support, operating hours |
| Capability | Business capability, functional and non-functional requirements |
| Architecture | Layer, scope alignment, dependencies, approval status |
| Privacy | Personal information, special personal information, classification |
| Delivery | Project, programme, portfolio, PM, architects, change and rollback roles |
| Evidence | Minutes, business case, Jira, SharePoint and Confluence references |
| Operations | Incidents, changes and implementation iterations |

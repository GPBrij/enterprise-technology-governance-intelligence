# Repository Reporting Model

## Reporting dimensions

```text
TIME | CAPABILITY | APPLICATION | ASSET | LIFECYCLE | OWNER | VENDOR | ENVIRONMENT
STANDARD | WAIVER | RISK | ROADMAP | FORECAST | INVESTMENT | PATTERN | CONTROL
```

## View catalogue

| View | Audience | Measures and indicators |
|---|---|---|
| Executive portfolio | Executives and finance | Critical assets, high risks, migration priorities |
| Capability | Business and enterprise architects | Applications, assets, maturity and target states |
| Application portfolio | Application owners | Lifecycle, criticality, hosting and roadmap status |
| Technology landscape | Technology owners | Vendors, versions, EOL and dependencies |
| Standards compliance | Architecture governance | Compliant, waiver required and non-compliant |
| Waiver portfolio | Review forum | Expiring, overdue and conditional waivers |
| Risk portfolio | Risk and control owners | Inherent, residual, overdue and treatment status |
| Roadmap portfolio | PMO and finance | Milestones, target dates and blocked transitions |
| Pattern reuse | Solution architects | Pattern uptake, alignment and missing controls |
| Evidence quality | Governance and audit | Missing, linked, verified and stale evidence |

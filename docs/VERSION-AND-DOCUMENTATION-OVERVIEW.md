# Version and Documentation Iteration Overview

## Iteration line

```text
v1.0 ASSET FOUNDATION
   -> v1.1 STANDARDS
      -> v1.2 WAIVERS + RISKS
         -> v1.3 REPOSITORY + PORTFOLIO
            -> v1.4 ROADMAPS + FORECASTS
               -> v1.5 REFERENCES + PATTERNS
                  -> v1.5.1 DOCUMENTATION CONSOLIDATION
```

| Version | Primary capability | Primary entities | Primary decision | Related documents |
|---|---|---|---|---|
| v1.0.0 | Asset governance | TechnologyAsset, GovernanceAssessment | Approve, review, condition or replace | ARCHITECTURE, META-MODEL, DATA-QUALITY-MATURITY, CONTROL-CATALOGUE, DECISION-RULES |
| v1.1.0 | Standards governance | TechnologyDomain, TechnologyStandard | Compliant, review, waiver or non-compliant | TECHNOLOGY-REFERENCE-MODEL, TECHNOLOGY-STANDARDS-CATALOGUE |
| v1.2.0 | Exceptions and risk | ArchitectureWaiver, TechnologyRisk | Valid waiver and treatment decision | ARCHITECTURE-WAIVER-REGISTER, TECHNOLOGY-RISK-REGISTER |
| v1.3.0 | Architecture repository | Capability, Application, Landscape, Decision | Repository completeness | BUSINESS-CAPABILITY-MODEL, APPLICATION-PORTFOLIO, ARCHITECTURE-LANDSCAPE, GOVERNANCE-DECISION-LOG |
| v1.4.0 | Planning and forecasting | Roadmap, Forecast, Investment | Migrate, modernise, contain, retire or monitor | TECHNOLOGY-ROADMAP, LIFECYCLE-FORECASTING, INVESTMENT-PLANNING |
| v1.5.0 | Reusable architecture | Reference, Pattern, BuildingBlock | Aligned, conditional or not aligned | REFERENCE-ARCHITECTURE-LIBRARY, ARCHITECTURE-PATTERN-CATALOGUE, ARCHITECTURE-BUILDING-BLOCKS |
| v1.5.1 | Documentation consolidation | All entities and relationships | Documentation completeness | Executive, relationships, fields, controls, traceability, lifecycle, reporting, target-state and glossary |

# Architecture

```text
PORTFOLIO
   -> PROGRAMME
      -> PROJECT
         -> SOLUTION
            -> TECHNOLOGY ASSET
               -> APPLICATION | DATA | API | FRONT END | SECURITY | INTEGRATION | INFRASTRUCTURE

TECHNOLOGY ASSET
   -> lifecycle
   -> vendor/support
   -> owners
   -> business capability
   -> privacy classification
   -> incidents/changes
   -> architecture evidence
   -> target-state replacement
   -> landscape impact
```

The initial version uses transparent deterministic rules. A later AI explanation service can consume the assessment output but should not silently change control outcomes.
